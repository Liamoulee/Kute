Uncapped FPS

A hook on the game's swap chain holds any FPS limit exactly while the CPU idles, and counts the frames that actually reach your screen. The bundled Chromium is patched against the aim freeze and the stutter other uncapped clients get when the GPU is the limit.

  • D3D11
  • D3D11on12
  • OpenGL
  • Vulkan
AUTO-DETECT≈ 1 MIN
SCAN

Auto-Detect

Plays a private test match and measures what each graphics setting costs on your PC. Only the settings that make a real difference get lowered. A PC that is already fast enough keeps its settings.

  • Client and game settings
  • Undo
  • Needs an account
INPUTRAW

Raw input

Mouse movement comes straight from the device, without Windows pointer acceleration. Scrolling can jump for easier ramp boosts, and that turns itself off in competitive.

  • No acceleration
  • Ramp boost

All features

Nearly all of them are settings in Krunker's settings menu and can be turned off.

Performance Gameplay Lobbies and ranked Interface Customization Client

Performance

Bundled Chromium

Kute ships its own Chromium (CEF). Nothing else to install.

Patched Chromium

Two patches: no aim freeze with uncapped FPS, no stutter when the GPU is the limit.

Uncapped FPS

Removes the refresh rate cap.

Exact FPS limit

Held by the swap chain hook, so the CPU idles between frames.

Present FPS counter

A second counter for the frames that reach your screen.

Auto-Detect

Measures your PC in a private match and sets the client and the game up for it. Can be undone.

Graphics backend

D3D11, D3D11on12, OpenGL or Vulkan, plus a color profile setting.

Chromium flags

A tested default set. Add your own in user_flags.json.

URL blocklist

About 50 entries against ads and trackers. Add your own.

Priority and CPU throttle

Process priority, and a CPU throttle for PCs where nothing else helps.

Gameplay

Raw input

Mouse input without acceleration.

Ramp boosting

Scrolling jumps. Off in competitive.

Real Ping

Pings the lobby server and shows your actual latency.

Player list ping

Everyone's ping as a number.

Hardpoint enemy counter

How many enemies are on the point in competitive.

Headshot sound

The headshot sound on every kill.

Auto spectate

Joins public matches as a spectator.

Lobbies and ranked

Matchmaker

F6 joins the lowest ping lobby that fits your filters: region, mode, map, players, time left.

Ranked queue

Queue for ranked from a small window without the game open.

Rank progress

Elo progress to the next rank and the rank distribution.

Shortcuts

F4 new lobby, F5 reload, F11 fullscreen, F12 devtools.

Interface

Better chat

Team and all chat in one view, Tab switches where you send. Chat text can be selected.

Menu timer

The match timer in the menu.

Cleaner menu

Hides menu clutter and store popups, adds an exit button.

Clan colors

Colored clan tags in the player lists.

HUD editor

F7 opens it: drag, resize and hide every HUD element, snapping to the edges and to each other.

Nuke counter

Your career nuke total in game, with an optional goal. Place it where you want it.

Kute badge

Shows who else in the match runs Kute. The server only sees hashes, never names.

Battle pass claim-all

Claims every open reward at once.

Discord Rich Presence

Shows your mode and map on Discord.

Customization

Resource swapper

Replaces game files with the ones in your swapper folder.

Userscripts

Runs the .js files in your scripts folder, the social page included.

Settings import

Pick which parts to import: keybinds, sensitivity, sound.

Client

Account manager

Saved accounts, encrypted by Windows. Passwords never reach the page.

OBS capture

An OBS source that takes the frames straight from the game, plus a separate audio window.

Auto-updater

Updates the client, and script fixes arrive without a reinstall. Shows a changelog.
