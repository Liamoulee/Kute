2. This website

kute.lol is served by our own server behind Cloudflare. To deliver the pages, Cloudflare and our server process your IP address and the usual request data (URL, browser, time). This is technically necessary (Art. 6(1)(f) GDPR). Our server's application log records the requested path, not your IP address, and is deleted after 31 days.

The website sets no cookies and uses no analytics or tracking. It loads the current player count from our own server.

3. The Kute client

Telemetry (opt-out)

Unless you turn off the telemetry setting (Settings, About), the client sends us:

  • Auto-Detect results after a run: GPU and CPU model, thread count, RAM, Windows build, display resolution and refresh rate, whether the PC runs on battery, the client and game graphics settings, and the measured frame rates.
  • Crash reports: client version, where the crash happened, the error message and stack trace. Paths of your user folder are removed before sending.
  • Script errors of the client itself (not of Krunker or your userscripts), at most three per page load.

The server rebuilds every report from a fixed list of fields and drops everything else. Reports are stored with the day only, without IP address, account or any id. Hardware details can still describe a PC, which is why we call this pseudonymized and not anonymous. Legal basis: our legitimate interest in fixing and tuning the client (Art. 6(1)(f) GDPR). You can object at any time by turning the setting off. We keep reports while they help development and delete them when they no longer do.

Kute badge and player count

While the client runs, it keeps a connection to our server. When you are logged in to Krunker, it sends a hash of the lobby id and your in-game display name, so that other Kute users in the same match can see the Kute badge next to you. The hash is only held in memory while you are connected and is never stored. The server also counts open connections (current number and peak) and how many clients were started for the first time. The client remembers itself that it was counted, the server keeps no list.

This is part of how the client works, so the telemetry setting does not affect it. If you do not want any contact with our server, add *://kute.lol/* to user_blocklist.json in Documents\kute. The client plays the same without it.

Rate limiting

To protect the server from abuse, request counts are kept per IP address. The address is replaced by a salted hash in memory. The salt is never stored and changes on every restart. Entries are deleted within 75 minutes. The same hash keeps a first start from being counted twice on one day and is dropped the next day.

Other services

  • Updates: the client checks GitHub (api.github.com, raw.githubusercontent.com) for new versions. GitHub's privacy statement applies to these requests.
  • Krunker: the game itself is run by its operator. Their privacy policy applies. Kute does not change what Krunker collects.
  • Discord: with Rich Presence on, the client tells the Discord app on your PC your current mode and map. Discord's privacy policy applies.

Stored only on your PC

Settings, userscripts, swapped files, the browser cache and saved accounts stay in Documents\kute. Saved account passwords are encrypted with Windows (DPAPI) and are never sent to us.
